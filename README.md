# 3D Slot Machine

3D Slot Machine est un petit projet découverte du framework React Three Fiber issu de la librairie Three.js. Modélisant une machine à sous de casino, le but est de remporter le plus de pièces fictives possible via une combinaison de 3 symboles identiques lors du roulement de la machine.

## Stack

- React
- TypeScript
- React Three Fiber
- Sass
- Vite

## Interactions

- Tourner la caméra avec clic droit
- Insérer une pièce dans la machine avec clic gauche
- Tirer le levier en maintenant clic gauche pour lancer la machine

## Animations

- Lancement du jeu via un zoom
- Pièce insérée dans la machine
- Levier réaliste
- 3 Rouleaux tournant s'arrêtant de manière différée et aléatoirement sur différents symboles
